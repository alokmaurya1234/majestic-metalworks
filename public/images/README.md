# Public images

Place approved, web-ready website images here. Suggested folders:

```text
images/
  facility/
  products/
  projects/
```

Use descriptive lowercase filenames and optimized WebP or AVIF where the
source quality allows it. Keep originals outside the public site assets. Check
client usage rights and supply meaningful alt text in the page content.

Record each selected image's source, creator, licence, intended use, and owner
approval in [the asset inventory](../../docs/asset-inventory.md).
