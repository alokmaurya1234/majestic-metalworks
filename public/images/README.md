# Public images

Research collection folders:

- `branding/` — company logo from the original website.
- `source-site/` — downloaded media from the original company website,
  organized by the page where it appears.
- `curated/architecture/` — Pexels stock imagery for architectural inspiration.

Website-hosted images are not automatically verified project photos or proof
of ownership. Curated stock must never be presented as company work. Confirm
rights and intended use with the owner before publishing. See the
[asset inventory](../../docs/asset-inventory.md) for source URLs, dimensions,
and license/provenance notes.
